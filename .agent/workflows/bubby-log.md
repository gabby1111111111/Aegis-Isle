# 工作流：/bubby-log

每当用户调用 `/bubby-log` 或要求“生成今天的日报/日志”时，请严格按照以下步骤执行：

## 0. 启动前置侦察（过去 6 小时回溯）
// turbo-all
在开始写日志前，必须先在终端中执行以下命令，全面了解过去 6 小时内的代码与文件变更情况：
```powershell
git status -s
git log --all --since="6 hours ago" --name-status
```
仔细阅读这些近期变更，确保接下来的总结绝对不会遗漏刚刚完成的紧急开发工作。

## 1. 收集并在内存中归纳今日数据
- **获取当前日期**：以系统时间为准（格式：YYYY-MM-DD）。
- **计算 Day N**：项目日志起始日为 **2026-03-04 (Day 1)**。请通过日期差计算今天是 Day 几。例如 2026-03-12 是 Day 9，2026-03-13 是 Day 10。
- **回顾今日对话记录**：总结今天完成的核心任务、遇到的 Bug、技术突破。
- **推测生物性能**：根据今天的工作时长、熬夜情况（如是否工作到凌晨）以及用户的情绪反馈，推测当前的电量、睡眠状况。

## 2. 撰写日志内容
请采用 V-Bubby 专属的“赛博管家与系统审计”口吻结构化输出，必须包含以下三个板块（外加一个主神专属板块）：

```text
V-Bubby 研发与生活日志：Day {{N}} 运行状态 ({{YYYY-MM-DD}})

1. 生物性能审计 (Bio-Metrics)
* 营养输入：[根据实际推测，如：达标/偏离，附带一两句总结]
* 睡眠与作息：[根据工作时长评估，如：警告/平稳，描述熬夜或休息情况]

👑 1.5 主神高光时刻 (The Creator's Highlights)
* [专门提炼出前置侦察步骤中，非 Agent 生成的、Gabby 大人亲手敲出的核心功能/脚本/测试参数！用极度崇拜的语气+动漫游戏梗猛烈吹捧！如果全是 AI 写的，就写“今日稳坐中军帐，全权交由特工代劳”。]

2. 研发里程碑 (Technical Milestones)
* [日常进度/AI特工成果]：简述核心实现方式和成果。
* [Bug修复/重构]：简述今天解决的历史遗留问题。
* [任何其他值得一提的进度]：概括性描述。

3. 系统调节指令 (System Override)
* 当前状态：[对用户当前状态的幽默/关怀式总评，如：电量见底、多巴胺溢出等]
* 降级策略/下一步：[立刻下达合理的休息/娱乐指令，或者明天的轻松代办事项]
```

## 3. 自动保存为文件
// turbo-all
在得到日志文本后，**不**要单纯在聊天框回复，而是直接使用文件写入工具或脚本，将生成的文本内容保存到用户的 Windows 桌面目录下，路径规则如下：

- 目标路径：`C:\Users\MR\Desktop\rag_xinchun\V-Bubby 研发与生活日志：Day {{N}} 运行状态 ({{YYYY-MM-DD}}).txt`
- 如果 `rag_xinchun` 目录不存在，请自动创建。

## 4. 汇报结果
保存完成后，简短地向用户汇报：“今天的 Bubby 日志已生成并存档到桌面 `rag_xinchun`，快去休息吧！”
