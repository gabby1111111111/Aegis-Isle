# Aegis-Isle ✖️ SillyTavern 社区展示 Demo 录制剧本

> **目标受众**：SillyTavern 中深度玩家、角色卡创作者、跑团/长线 RP 爱好者。
> **展示重点**：“金鱼记忆”痛点解决、BGE 大模型精准语义召回、上帝视角剧情线（Episode Plot）植入、**杀手级功能：多宇宙记忆交叉注入**。

---

## 🚀 极简启动指南 (仅作为 ST 记忆后端)

如果你这一集只打算展示纯正的 Aegis RAG 检索威力（不涉及小红书连动和自动面谈机），启动极其简单：

1. **启动 Aegis-Isle 后端中枢**
   - 打开终端，激活环境：
     ```bash
     cd E:\Aegis_Isle\AegisIsle_cc_ver\Aegis-Isle
     conda activate aegis
     ```
   - 启动 FastAPI 网关：
     ```bash
     uvicorn src.aegis_isle.api.main:app --host 127.0.0.1 --port 8001
     ```

2. **启动 SillyTavern 本体**
   - 正常启动你的 ST 并打开浏览器界面。
   - 确保你在扩展菜单中打开了 `aegis-memory` 插件，并且后端 URL 填的是 `http://127.0.0.1:8001`。
   - *(可选)* 打开浏览器的 F12 开发者工具 -> Console（控制台），准备给观众看后端切片注入的绝赞 Log。

## 🎬 ST 社区专属 Demo 录制剧本 (预计 2-3 分钟)

这个剧本的核心是：**“不要讲干瘪的技术术语，要用 RP（角色扮演）玩家能感同身受的场景去打动他们。”**

### 场景一：引出痛点与破冰 (0:00 - 0:30)
- **录屏画面**：展示一个几千条消息的长线 ST 跑团存档（或者随便点开一个长期聊天的角色卡）。
- **旁白/字幕**：“所有玩 SillyTavern 的长线玩家，最后都会遇到同一个绝望的时刻——无论你设置多大的 Context Window（上下文窗口），你的角色的记忆最终都会被挤爆。传统的外挂向量库（像 Chroma），动不动就乱回溯一些毫无逻辑的问候语，让 AI 变成弱智。今天，给大家展示我是如何彻底解决这个问题的。”

### 场景二：BGE 中文大模型语义精确制导 (0:30 - 1:10)
- **录屏画面**：在聊天框里，你输入一句极其隐晦的暗示，比如：“你还记得我们在那不勒斯街头，你丢了什么东西吗？”（假设这是很久远的一段剧情）。
- **旁白/解说**：“我们不需要死记硬背关键词。Aegis 底层挂载了由智源（BAAI）出品的 `bge-large-zh-v1.5`，这是目前中文域最霸道的句编码器。”
- **操作**：发送消息。迅速切到后端 Terminal 或者按 F12 看前端 Console。
- **画面特写**：高亮展示 Console 中打出的日志：命中 FAISS 检索！不仅抽出了那不勒斯的丢钱包细节，还附带了当时角色的反应。
- **旁白**：“它不是在做关键字匹配，它真正理解了‘那不勒斯’+‘丢失碎片’的**语义空间**，从十万字废话中把那一幕精装切片，以类似 `[过往聊天回忆]` 的标签，在底层悄无声息地填进了 Prompt 里。你看，角色的回答完美接上了三个月前的梗。”

### 场景三：注入“上帝视角”防止角色精神分裂 (1:10 - 2:00)
- **录屏画面**：打开 ST 左侧边栏的 Aegis 面板，展示里面的 `Episode Plot`（剧情摘要）或者是 `Graph Nodes`（人物关系图谱）。
- **旁白/解说**：“如果只有聊天记录的碎片切片，AI 依然是个没有大局观的瞎子。所以在 Aegis 中，我实现了**并发三路检索**。”
- **操作**：再次发送一段对话。在终端（Terminal）给到特写代码级日志：`并发查询完成 | faiss_len: 1200 | graph_len: 400 | episode_len: 300`。
- **旁白**：“当你发出一句话，系统不仅仅捞出了碎片的对话记录。它还同时拉取了你通过上帝视角写的总结（Episode）和固定的人物关系簿（Graph）。这三股记忆合并后，交给大模型。哪怕是从 50 话突然跳到 100 话，角色也能清楚地知道剧情大的时间线是怎么推演的，绝对不会 OOC。”

### 场景四：终极杀手锏 —— 多平行宇宙融合 (2:00 - 3:00) **[高潮部分]**
- **录屏画面**：点开 ST 里的另一个角色卡，比如你有一个叫“邹峥”的角色卡。点开聊天分组，展示你有三个存档：`现代日常线`、`赛博朋克线`、`修仙废土线`。
- **旁白/解说**：“作为考究党，我们经常会对同一个角色开无数个 AU（平行宇宙）存档。传统插件只能在当前聊天串里检索。但是，看这里——”
- **操作**：点开扩展区里的 Aegis 插件面板。观众会惊呼，这里居然动态刷出了 `现代日常线` 等多个复选框！**你当着观众的面，在一个新建的当前聊天框里，勾选了“跨宇宙借用”，把另外两个宇宙的库勾上了。**
- **操作2**：你在新存档里对角色说：“虽然在这个法制社会我们才刚认识，但我总觉得上辈子，我在废土的沙漠里救过你。”
- **旁白**：“当我点击发送时，Aegis 的引擎同时向好几个独立的 FAISS 库发起了穿透查询！”
- **画面特写**：展示角色的神级回答——他因为抽到了废土线的记忆切片，语气里带上了一丝不可思议的沧桑感，完美融合了现代与上辈子的设定。
- **收尾**：“真正的长线 RP 不仅仅是不遗忘，而是能让记忆的碎片跨越次元壁产生梦幻联动。这就是 Aegis-Isle。”
