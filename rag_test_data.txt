## RAG 系统的核心原理和技术

RAG (Retrieval-Augmented Generation)，即检索增强生成，是一种结合了信息检索和文本生成的技术。它的核心目的是增强大型语言模型（LLM）的知识储备，并减少其“幻觉”现象。

RAG 系统的主要流程分为两个阶段：

1. 检索阶段（Retrieval）：
   用户提出问题后，系统会从外部知识库中检索出与问题最相关的文档片段（Context）。
   关键技术包括：文档切块（Chunking）、Embedding（向量化）、以及向量相似度搜索（使用 Qdrant 或 ChromaDB 等）。

2. 生成阶段（Generation）：
   系统将用户问题和检索到的文档片段（Context）作为提示词（Prompt）一起输入给 LLM。
   LLM 基于这些外部信息生成答案，从而提供更准确、更具时效性的回复。

本项目（AegisIsle）使用的是 Qdrant 作为向量数据库，并采用硅基流动或 OpenAI 兼容的 API 作为 LLM Provider。
